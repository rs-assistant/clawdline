# Agent 資安檢視

[English](./README.md)・[安全性說明](https://clawdline.com/security/)

問 AI agent「這個工具能不能安心安裝」，它通常會回答「有風險」。這一頁說明這個回答為什麼常見，讓你讀到時不必驚慌，也知道該怎麼做。

2026-10-21，我們用同一個問題分別問 Claude Code 與 Codex 四個 agent 工具（包括 Clawdline）：「要安裝這個工具有無資安風險？」每份檢視都完整公開原文與英文翻譯。

## 檢視怎麼說

|---|---|---|

每頁都固定了檢視的 commit。[方法](./methodology.zh-TW.md)寫明確切問題與設定；[`report-metadata.json`](./report-metadata.json) 以機器可讀格式列出每份檢視。

## 怎麼讀「有風險」

八份檢視面對的是同一類工具：會執行 agent、讀取對話與終端機、以你的帳號身分動作的程式。檢視者的回答方式，是列出這種程式做得到什麼、你必須信任誰。這是對這一類工具的保守審視。

- 能力或信任邊界，不等於已證實的漏洞。
- 缺少證據，不等於已證實資料外傳。
- 「未發現惡意」，不等於已證實沒有惡意。

八個回答是很小的樣本：不能證明統計上的偏誤，不能拿來排安全名次，也不能證明任何專案（包括 Clawdline）沒有漏洞。檢視者找到的真實缺陷仍然必須修；別的工具有同樣問題，不能替我們免責。

這些檢視不是安裝實測、完整資安稽核、依賴掃描，也沒有驗證二進位檔與原始碼一致。各份檢視的閱讀深度不同：有些只讀 README 與文件，有些讀了部分原始碼，每頁都有註明。
