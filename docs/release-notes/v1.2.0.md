# Clawdline v1.2.0

**Phones reach terminals more directly, the Board keeps up with your squad, and a machine does less work while nobody watches.**

- **Connect directly on the same network.** A new setting, off by default, lets a phone on the same Wi-Fi connect straight to its machine. Every direct attempt leaves one content-free line in the daemon log, and a terminal keeps its lease when the direct path fails. AWS Linux machines can be set up for a direct phone connection too.
- **Assign work with a picker that tells the truth.** The Board's Session picker shows that its list is loading, failed or incomplete instead of an empty list, and a Session working in one of the Project's worktrees can be assigned. An Agent can cancel a Board item when you ask, and a Plan turned into work no longer copies its analysis in as steps.
- **Keep child Sessions under their root.** A dispatched child stays nested under the Session that started it across list refreshes, Cloud rereads and reused tabs.
- **Trust the machine status on Schedules.** The Schedules page no longer calls an online Mac offline, and it separates a machine that is offline from one whose read failed.
- **Answer Codex like Claude.** Codex questions appear with their choices, and a denied Codex tool request shows in the Session's transcript. Sessions show their model before the first message and name their reasoning effort.
- **Use terminals more comfortably on a phone.** A hosted terminal shows a loading layout, says when it has ended, and types into the screen directly. The key row clears the home indicator, and tapping outside a terminal menu closes it.
- **Work with pictures and workflows.** Pictures load newest first, open at their original size, and save through the phone's file sheet. Workflow sheets use more of the screen, and a saved workflow can be edited or deleted from its launch review.
- **Dictate on the right machine.** Dictation follows the machine that owns the current Session, and Linux voice setup installs a verified local model.
- **Let paired machines find each other's work.** Paired machines can find each other's Projects and wake each other's Sessions.
- **Spend less while idle.** The task list stops rebuilding every finished task every two seconds, an open app with a staged update stops running `ps` every two seconds, a terminal viewer stops sampling tmux four times a second, and a machine nobody watches stops building Session rows. Event and effect rows that nothing reads back now expire instead of growing the store.
- **Simpler and safer underneath.** Pairing alone now decides who may use a terminal. The daemon no longer reads the retired Swift app's state, and the console speaks its chosen language again instead of falling back to English.
