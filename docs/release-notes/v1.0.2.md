# Clawdline v1.0.2

The one-line installer now finishes its first-session check when a Project's rules or skills cannot be read promptly. The Project still appears in the list; its optional setup status stays unknown until that read completes. This also keeps the Project picker responsive when one checkout stalls.

This release follows v1.0.1, which added a bounded Git origin lookup. A live v1.0.1 install exposed a second blocking read in the Project setup plan: `GET /v1/places` waited past the installer's 30-second deadline in `os.OpenRoot`. The new lookup waits at most one second per list request, with at most four active setup readers and forty remembered paths.
