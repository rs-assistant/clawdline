Clawdline 1.0.1 makes the update notice explain what happens before and after the brief restart.

The version panel now says that a release download is checked before Clawdline switches versions,
that a new version which fails to start is rolled back, and that existing tmux Sessions keep
running. The English and Taiwan Traditional Chinese messages carry the same information.

This release also updates the README's version status after the first stable release.
