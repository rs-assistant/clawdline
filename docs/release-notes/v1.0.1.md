Clawdline 1.0.1 makes the update notice explain what happens before and after the brief restart.

The version panel now says that a release download is checked before Clawdline switches versions,
that a new version which fails to start is rolled back, and that existing tmux Sessions keep
running. The English and Taiwan Traditional Chinese messages carry the same information.

This release also updates the README's version status after the first stable release.

The macOS app now declares the same macOS 13 minimum in its executable as in
Info.plist. The first stable release's app executable required macOS 26 despite
its Info.plist saying 13, so macOS 13–15 refused to open it. The release build
checks the actual minimum of every bundled executable before signing.

The Project list now answers even when macOS holds a Git config read while
deciding whether a newly signed release may access that checkout. Repository
metadata from that checkout appears when the read finishes; it no longer
blocks the installer’s terminal check or the whole Project list.
