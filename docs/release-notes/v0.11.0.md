Clawdline 0.11.0 makes the one-line install lead into the first Session and Cloud pairing flows.

## Install and start

```sh
curl -fsSL https://raw.githubusercontent.com/sainteye/clawdline/main/install.sh | sh
```

The installer verifies the release, installs a per-user service, and opens the console. On an
Apple silicon Mac it also installs the app. The release carries tmux when a suitable system tmux
is unavailable; Go, Node.js, Git, Homebrew, and administrator access are not required for the
usual install. The Mac app can guide installation and sign-in for Codex with explicit consent.

When the Session list is empty, the console now points to starting the first Session. Its folder
browser registers an **existing** work folder as a Project after confirmation. Choose that
Project and a signed-in AI tool to start a Session. On Linux and other supported machines, the
browser and terminal paths remain available. See the [installation guide](https://github.com/sainteye/clawdline/blob/main/docs/user/install.md).

## Connect a phone

The local console guides Cloud sign-in, machine connection, browser pairing, and operation
permission separately. The phone pairing panel can scan the desktop QR with the camera or decode
a photo or selected image; copying the full pairing offer remains available. The Cloud machine
list shows each machine's connection, pairing, operation, version, compatibility, and update
state. Each machine has its own pairing and operation permission.

## Updates

Settings and the Cloud machine list report the running version and available update per machine.
An update is still opt-in unless automatic installation was enabled on that machine. A failed
startup rolls back to the previous release and reports the reason. Existing tmux Sessions stay
outside the daemon process.

The one-line command is the supported public download. A notarized Mac disk image is a future
release plan and is not included in these assets.
