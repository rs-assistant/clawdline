# Clawdline v1.1.1

**Updates are checked when you return, and active work stays easier to follow.**

- **See current update information when opening Clawdline.** The Mac app, Console, and phone view check the release source when opened or brought back to the foreground. If that check fails, the current installation details remain visible without presenting an unverified latest release.
- **Keep cancelled Board items out of the open list.** A cancelled item leaves the open list when its detail updates.
- **Open the Board sooner.** Slow or failed Session, proposal, decision, and Epic-family reads no longer hold up the Board's item list.
- **Keep callback context with its caller.** A callback now records the Session that called it, so follow-up coordination can identify that Session directly.
- **Start your first Session more easily on a phone.** The button for an empty Session list sits below its hint, with space between the two.
