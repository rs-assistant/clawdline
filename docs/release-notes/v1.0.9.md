# Clawdline v1.0.9

**Clawdline asks macOS for fewer permissions.**

- **Signed with one certificate.** The app and the daemon were signed ad hoc, so every update was
  another program to macOS, and everything the person had allowed was asked again: Dropbox, the
  local network, the keychain password behind "Clawdline Next WebCrypto Master Key", control of
  iTerm. From this release they are signed with one certificate. Subsequent
  investigation found that the self-signed certificate did not preserve
  WebKit's keychain grant, and the daemon's versioned path still changed its
  Automation identity. A later release must address both before repeated
  prompts can be considered fixed.
- **No Dropbox prompt.** A folder in Dropbox, Google Drive, OneDrive or iCloud Drive where Claude
  Code or Codex was once run is no longer listed as a Project, so Clawdline does not read it in the
  background. A folder you add yourself, or one a running Session is in, is listed as before.
- **No local-network prompt.** The Cloud direct path no longer sends anything to the local network:
  it connects over public addresses, and a viewer on the same network that cannot reach the
  machine that way uses the relay, as any viewer without a direct path does.
